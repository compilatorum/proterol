## 5. Maturity as state

State ∈ {dream, plan, doing, celebrate, stalled, archived, regenerative}

A node is not better merely because it is more mature. An intentionally preserved Dream can be more valuable than a prematurely productized MVP.

## 6. Evidence model

Each node should eventually carry: source; semantic genes; dependencies; inputs; outputs; maturity; evidence; effort; cost; yield; risks; next experiment; celebration criterion.

Minimal node:

n = ⟨id, source, phase, orientation, state, inputs, outputs, deps, genes, evidence, effort, cost, yield, risk⟩

## 7. Critical songline

CP* = argmax_path [value × evidence × regeneration] / [effort × (1 + risk)]

The critical path is therefore not merely the longest schedule. It is the most consequential constrained route through the ecology.

## 8. Metabolic accounting

Financial balance: B(n) = Cost(n) − Income(n)

Plural yield: Y(n) = cultural + cognitive + relational + experimental/computational + financial

Portfolio value ≠ revenue. Revenue is one observable of a wider metabolic system.

## 9. Anti-patterns

- Repository monoculture: one repo = one product = one KPI.
- Premature tokenization: minting before provenance, evidence and semantic identity.
- AI as autonomous authority: recommendations bypass evidence gates.
- Infinite ideation: Dreaming without bounded experiments.
- Infinite implementation: Doing without celebration and reintegration.
- False completion: deployment is treated as the end rather than a new observation.
